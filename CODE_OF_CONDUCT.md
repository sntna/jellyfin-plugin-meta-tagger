# Code of conduct

## Our standard

Contributors and maintainers are expected to be respectful, specific, and constructive. Discuss the work rather than the person. Welcome questions, assume honest mistakes, and make room for people with different levels of experience.

Unacceptable behavior includes harassment, threats, discrimination, sexualized attention, deliberate disruption, publishing private information, or pressuring someone to disclose credentials or personal server data.

## Scope and enforcement

This standard applies in repository issues, pull requests, reviews, discussions, and other project spaces. Maintainers may edit or remove content and may temporarily or permanently restrict participation when behavior threatens the safety or usefulness of the project.

Report conduct concerns privately through the maintainer contact options on the repository owner's GitHub profile. Do not use a public issue when doing so would expose personal information.

  • manual:tagger:skip. Skip this item. The plugin does not change its tags or its tag records, including when removing plugin tags.
  • manual:tagger:lock. Older name for manual:tagger:skip, with the same effect. This tag does not lock metadata in Jellyfin.
  • manual:tagger:force. Check this item during a scan of new or changed items, even when it looks unchanged. Locks and skip tags still take priority. Remove the tag when you no longer need it.
